CAPSSTONE PROJECT:
The overall main point of this project was to predict whether a passenger survived the Titanic disaster. The machine learning model, specifically a RandomForestClassifier, was trained on historical data to learn patterns associated with survival.
After training and hyperparameter tuning, the best model was used to make a prediction for a new, hypothetical passenger. Based on the input features for that passenger, the model predicted their survival status.

PCA DECOMPOSITION:
                    Principal Component Analysis (PCA) is an unsupervised, linear dimensionality reduction technique used to simplify complex datasets while retaining as much variance (information) as possible.

RANDOM FOREST VS GRADIENT BOOSTING:
                   For big tabular datasets, Gradient Boosting (specifically LightGBM or XGBoost) is the best choice. It handles massive row counts efficiently, consumes less memory, runs faster during both training and inference, and consistently delivers superior predictive performance.
